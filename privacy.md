# Privacy policy for Marketing Hub Publisher

Marketing Hub Publisher is a self-hosted tool I run to publish posts and videos I have approved to my own accounts, through each platform's official API (the YouTube Data API, the X API, Bluesky and Mastodon).
It is not offered to anyone else.

## What it accesses

- With the permission granted on Google's consent screen, it uploads videos to my own YouTube channels and reads which channel that permission is for.
- On the other platforms it posts to my own accounts with the permissions I grant there.
- It does not read, collect or store data about any other person.

## What it stores

- The access tokens each platform issues, on my own server, readable only by the tool.
- A record of what it posted and where, for my own records.

## Sharing

- Nothing it handles is sold or shared with anyone.

## Revoking access

- Google access can be removed at any time at [myaccount.google.com/permissions](https://myaccount.google.com/permissions).

## YouTube API Services

- The tool uses YouTube API Services. See the [YouTube Terms of Service](https://www.youtube.com/t/terms) and the [Google Privacy Policy](https://policies.google.com/privacy).
